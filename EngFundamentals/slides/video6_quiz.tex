\begin{enumerate}
  \item What values are added to $\mathbb{R}$ to form the extended real numbers in the video?
  \begin{enumerate}
    \item $0$ and $1$.
    \item $\sqrt{2}$ and $-\sqrt{2}$.
    \item $\infty$ and $-\infty$.
    \item All complex numbers.
  \end{enumerate}

  \item In the video, when is a continuous function called uniformly continuous?
  \begin{enumerate}
    \item When $\delta$ can be chosen independently of $x_0$.
    \item When $\epsilon$ equals $\delta$.
    \item When its domain is the real numbers.
    \item When its range is bounded.
  \end{enumerate}

  \item For $f(x)=1/x$ on $X=(0,1]$, what conclusion does the video reach?
  \begin{enumerate}
    \item It is neither continuous nor uniformly continuous.
    \item It is continuous but not uniformly continuous.
    \item It is uniformly continuous but not continuous.
    \item It is both Lipschitz and uniformly continuous.
  \end{enumerate}

  \item What does the video state about uniformly convergent sequences of continuous functions?
  \begin{enumerate}
    \item Their limit function is continuous.
    \item Their limit function is always constant.
    \item Their limit function must be Lipschitz continuous.
    \item They converge only pointwise.
  \end{enumerate}
\end{enumerate}
