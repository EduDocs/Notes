  \item Which set does the video use as an example of a countably infinite set?
  \begin{enumerate}
    \item The rational numbers $\mathbb{Q}$.
    \item The real numbers $\mathbb{R}$.
    \item The set of all subsets of $\mathbb{R}$.
    \item The empty set $\emptyset$.
  \end{enumerate}

  \item Which pair does the video name as examples of sets that contain themselves in naive set theory?
  \begin{enumerate}
    \item The set of all books published in 2007 and the set of natural numbers.
    \item The set of all sets and the set of abstract ideas.
    \item The positive prime numbers and the rational numbers.
    \item The standard English vowels and the universal set $U$.
  \end{enumerate}

  \item Which result does the video say is not covered in this class but is worth googling if students have not seen it?
  \begin{enumerate}
    \item A listing proof that the rational numbers are countable.
    \item Cantor's diagonal argument.
    \item De Morgan's rule for complements of sets.
    \item Set-builder notation.
  \end{enumerate}
